# Agent Instructions

These instructions apply to the entire repository.

1. Read `docs/SPEC.md` and `docs/STATUS.md` before making changes.
2. Implement only the requested milestone. Do not pull later work forward.
3. Preserve the working architecture described in `docs/ARCHITECTURE.md`.
4. Avoid unrelated refactors and changes outside the requested scope.
5. Do not leave placeholders, stubs, fake results, or TODO-only behavior in functionality declared complete for the current milestone.
6. Run the tests and build checks relevant to every change.
7. Repair relevant failures before stopping. If a failure cannot be repaired, record the concrete blocker in `docs/STATUS.md`.
8. Update `docs/STATUS.md` accurately before completing a milestone.
9. In the final handoff, summarize only:
   - files changed;
   - tests and validation commands run;
   - remaining blockers.
